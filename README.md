# 💰 AI-Driven Capital Allocation Advisor

An intelligent decision-support system for corporate finance. This app uses **Random Forest** to predict project success and **Linear Programming (PuLP)** to solve the 'Knapsack Problem' of budget allocation.

## 🚀 Features
- **Predictive ROI:** Estimates project value using Machine Learning.
- **Financial Engineering:** Automates NPV and Payback calculations.
- **Portfolio Optimization:** Selects the best projects within a fixed budget.
- **LLM Commentary:** Uses Google Gemini to write financial justifications for each decision.
